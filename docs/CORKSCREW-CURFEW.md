# Corkscrew Curfew

Press Pit sticky receipt → Vineway side stunt (same pattern as Tippler's Receipt / Sommelier Speedrun).

1. Peel the curfew waiver receipt in Press Pit (`press-curfew-receipt`).
2. Clue copy: `CURFEW WAIVER // SIGNED IN INVISIBLE INK // HOLD PHONE TO BLACKLIGHT LAMP IN CELLAR B.`
3. Vineway sideview unlocks the bounce stunt: dash the stolen corkscrew into the velvet rope so it rebounds into the emergency cork-pop lever before vinegar fog fills.
4. Success awards `corkscrew-curfew` mastery.
