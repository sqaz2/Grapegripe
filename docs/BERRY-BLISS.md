# Berry Bliss — platform brawler side mode

Retarget of the Berry Beef arena into a wine-world platform fighter (N64-era brawler feel, original satire only).

## Controls (must match the main journey)

| Action | Keyboard | Touch |
|--------|----------|-------|
| Move | WASD / arrows | Left joystick |
| Jump | ↑ / W | Stick up |
| Attack | Space | Attack button |
| Dash | Shift | Dash button |
| Pause | Esc | Pause |

Berry Bliss must **not** invent a separate scheme (no X-to-hit, no Space-to-jump).

## Feel targets

- Percent damage + knockback that scales launches
- Stocks lost by leaving blast zones
- Distinct grounded vs aerial attacks
- Edge / lip awareness with a short ledge grab
- Rival telegraphed stomp kept as a readable punish beat
